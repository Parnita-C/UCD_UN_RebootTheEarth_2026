# SoilScout

A soil and farming decision-support prototype combining soil-map
exploration, crop-rotation recommendations, and carbon-practice
and financial scenarios.
https://soilscout-chi.vercel.app/

# Project Overview 

This project aims to do two things by levaraging a website and a chatbot

1. Give farmers in the Central Valley quick and fast recommendations about what to plant next using a recommender system. The recommender system collects input such as specific location in the Central Valley and crops planted in the last 3 reasons. Taking these inputs and external soil data  such as pH levels, organic soil matter to suggest optimal future crops outputting a score for each plant. The output consists of a score for each plant from a scale of 0 (not optimal for that soil at all) to 100 (extremely optimal).
